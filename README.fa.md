رهیاب یک کنترل‌صفحه سروری برای تانل است، برگرفته از Tunnel Studio Pro. داشبورد، بررسی سلامت و مانیتورینگ روی یک سرور (هاب) اجرا می‌شوند و تانل را می‌شود بین هر دو سرور ناوگان ساخت — نه فقط سرورِ میزبان داشبورد. وقتی تانل بالا آمد، نگهبانی مقیم روی سرور سمت ایران زیر نظرش می‌گیرد و لحظه‌ای که قطع شود برش می‌گرداند، و اگر لازم شد پروتکل را عوض می‌کند. یک قانون بالای همه قانون‌ها دارد: **فقط بهترین تانل بین سرورها را می‌سازد، زیر نظر می‌گیرد و دوباره برقرار می‌کند — و به هیچ پنل PasarGuard، کانفیگ‌ها، نودها و یوزرهایش، از هیچ راهی، دست نمی‌زند.**

## ✨ چه کار می‌کند؟

- 🔍 **بنچمارک واقعی** — تأخیر، جیتر، لاس و توان روی ترافیک واقعی برای هر پروتکل اندازه‌گیری می‌شود، با تاریخچه جدا برای هر پروتکل.
- 🏆 **انتخاب بر اساس داده واقعی** — پروتکل‌ها با میانه اندازه‌گیری‌های واقعی رتبه‌بندی می‌شوند، نه با اعداد ساختگی.
- 🚀 **نصب با یک دستور** — `install.sh` هاب یا نود را نصب می‌کند، BBR را روشن می‌کند و گواهی پنل را می‌گیرد (دامنه یا آی‌پی).
- 🔄 **سوییچ با یک کلیک** — از داخل داشبورد می‌شود تانل زنده را به پروتکل دیگری سوییچ کرد، با پنجره تأیید و بازگشت خودکار اگر پروتکل تازه در بررسی سلامت رد شود.
- 🛡️ **فیل‌اور با حافظه** — نگهبان اول همان تانل را برمی‌گرداند، بعد کاندیدها را می‌چرخد تا یکی سالم شود؛ مدار شکن ضدفلپ جلوی سوییچ‌های پی‌درپی سریع را می‌گیرد و تلاش ناموفق سهمیه را مصرف نمی‌کند.
- 👁️ **داشبورد زنده** — کارت جفت‌ها، گیج‌های سرور (CPU، حافظه، دیسک، آپتایم)، پینگ و توان واقعی، تایم‌لاین رویدادها و خط چیپ پروتکل‌ها که چراغ سبز چشمک‌زن، پروتکل فعال را نشان می‌دهد. نمودارها فقط از تاریخچه واقعیِ جمع‌آوری‌شده کشیده می‌شوند — نقطه‌ای نباشد، خطی هم نیست و هیچ‌وقت جعل نمی‌شود.
- 🔐 **دسترسی فقط با کلید** — هاب فقط با کلید SSH به سرورها می‌رسد؛ هاست ناشناس رد می‌شود؛ پسورد اپراتور با PBKDF2 هش می‌شود و سشن‌ها هم هش‌شده‌اند.

## 🌐 پروتکل‌ها

## 🧭 اصول ایمنی

۱. **فقط یونیت‌های خودش.** ابزار فقط سرویس‌ها و رول‌های فایروالی را می‌سازد، ری‌استارت و حذف می‌کند که تگ خودش را دارند — تانل‌ها و سرویس‌های از قبل موجود هیچ‌وقت دست‌کاری نمی‌شوند.
۲. **توقف هنگام تردید (fail-closed).** بررسی سلامت ناموفق، سوییچ را پیش از جابه‌جایی ترافیک متوقف می‌کند؛ اورلی ناموفق کریر زنده را دست‌نخورده می‌گذارد.
۳. **بازگشت خودکار.** اگر پروتکل تازه در راستی‌آزمایی رد شود، پروتکل قبلی خودکار برمی‌گردد.
۴. **هیچ سکرتی داخل درخت پروژه نیست.** کلیدها، پسوردها و توکن‌ها بیرون از ریپو هستند؛ کلید خود هاب git-ignored است و غیبتش از همه کامیت‌ها راستی‌آزمایی شده.
۵. **هیچ یکپارچه‌سازی‌ای با پنل نیست.** عمداً به هیچ سامانه مدیریت یوزر دسترسی ندارد — خروجی‌اش یک تانل سالم است و اینکه روی آن تانل چه می‌گذرد، کار خود اپراتور است.

## ⚡ شروع سریع

**نیازمندی‌ها:** سرورهای Debian/Ubuntu، پایتون ۳٫۱۱ به بالا، دسترسی روت روی سرور مقصد.

```bash
# ۱. دانلود نصب‌کننده (اگر دانلود نشود، با خطا می‌ایستد)
curl -fsSL -o /tmp/install-rahyaab.sh https://raw.githubusercontent.com/irluca/Rahyaab/main/install.sh

# ۲. اجرایش — منوی تعاملی (نصب هاب یا نود، BBR، گواهی پنل، به‌روزرسانی، وضعیت، حذف)
bash /tmp/install-rahyaab.sh
```

غیرتعاملی:

```bash
bash /tmp/install-rahyaab.sh --role hub --bbr --ip-cert --yes                                    # هاب + BBR + گواهی self-signed آی‌پی (با تمدید خودکار)
bash /tmp/install-rahyaab.sh --role hub --bbr --domain panel.example.com --email you@example.com --yes  # هاب + Let's Encrypt
bash /tmp/install-rahyaab.sh --role node --bbr --yes                                              # نود (بدون داشبورد)
```

**راه‌اندازی کامل — دو سرور خام، با یک دستور، بدون نیاز به متا.** روی سرور هاب، با دسترسی روت:

```bash
bash /tmp/install-rahyaab.sh --full-setup <node-host> --bbr --ip-cert --yes
```

این دستور هاب را نصب می‌کند، BBR را روشن می‌کند، گواهی پنل را می‌گیرد، کلید هاب را روی نود نصب می‌کند (پسورد روت نود فقط یک بار پرسیده و هیچ‌جا ذخیره نمی‌شود)، نود را از راه دور نصب می‌کند، جفت را ثبت می‌کند، تانل اول (GRE) را اندازه می‌گیرد و مستقر می‌کند و نگهبان را رویش نصب می‌کند. بعدش داشبورد را باز کنید و حساب اپراتور را بسازید — آن قدم در خود داشبورد می‌ماند و نصب‌کننده هیچ حسابی نمی‌سازد و به PasarGuard دست نمی‌زند.

بعد مرورگر را روی **https://YOUR-SERVER-IP:8890** باز کنید (به‌جای YOUR-SERVER-IP آی‌پی سرور هاب را بگذارید)، حساب اپراتور را بسازید (فرم راه‌اندازی فقط وقتی نشان داده می‌شود که هنوز حسابی نباشد)، سرورها را اضافه کنید، بنچمارک بگیرید، جفت بسازید و نگهبان را فعال کنید. اجرای دوباره نصب‌کننده امن است: دیتابیس و گواهی‌های موجود هیچ‌وقت بازنویسی نمی‌شوند.

**نکته‌ها:** Let's Encrypt برای آی‌پی خالی گواهی نمی‌دهد، پس مسیر آی‌پی self-signed است (مرورگر بار اول هشدار می‌دهد؛ اثر انگشت را نصب‌کننده چاپ می‌کند تا مقایسه کنید) و تایمر روزانه پیش از انقضا خودش تمدیدش می‌کند. فورک خصوصی برای مسیر دانلود به `GITHUB_TOKEN` (توکن خواندنی fine-grained) نیاز دارد، یا می‌شود با `--local` از روی کپی آپلودشده کد نصب کرد.

## 🧪 تست

کل قرارداد رفتاری پروژه یک سوئیت آفلاین است (بدون نیاز به هیچ سروری):

```bash
python -m pytest orchestrator/ -q
# ۱۷۶ تست + ۱۳ ساب‌تست — بنچمارک، فیل‌اور، گاردهای ایمنی، بهداشت اینستالرها و...
python -m pytest hub/ -q
# API هاب، داشبورد، بنچمارک‌ها، سوییچ
```

## 🗂️ ساختار

```
orchestrator/     موتور اثبات‌شده: بنچمارک، استقرار، نگهبان، فیل‌اور، هشدارها، سوئیت آفلاین
agent/            ایجنت مقیم Rust (فقط ری‌استارت، فقط گزارش)
hub/              رجیستری ناوگان، جفت‌ها، JSON API، کنترل نگهبان، جاب‌ها، لاگین
dashboard/        داشبورد تک‌صفحه‌ای تازه (راست‌به‌چپ، Vazirmatn، تم تیره)
install.sh        نصب‌کننده سرور (هاب/نود، BBR، گواهی‌ها، به‌روزرسانی، حذف)
*.sh              جفت‌های نصب مستقل (iran-*.sh / foreign-*.sh)
docs/             ران‌بوک‌ها (فازها، نظرسنجی پنل)
```

## 🗺️ وضعیت

- **فاز ۱ (پی‌ریزی)** — تمام شد ۲۶ اکتبر ۲۰۲۶: موتور و ایجنت پورت شدند، سوئیت سبز.
- **فاز ۲ (هاب)** — تمام شد ۲۶ اکتبر ۲۰۲۶: JSON API با پایتون خالص، CRUD ناوگان و جفت، کنترل نگهبان، جاب‌ها، رویدادها.
- **فاز ۳ (داشبورد)** — تمام شد ۲۶ اکتبر ۲۰۲۶: داشبورد تازه، سرو شده توسط خود هاب.
- **فاز ۴ (نصب لایو + تست‌ها)** — تمام شد ۲۶ اکتبر ۲۰۲۶: هاب روی سرور ایران، جفت لایو پذیرش شد، تست‌های لایو از روی API هاب پاس شدند و سوییچ اورلی هم به‌صورت لایو اثبات شد (کریر به کریر و کریر به اورلی).
- **فاز ۵ (ریپو + تگ)** — تمام شد ۲۷ اکتبر ۲۰۲۶: ریپوی عمومی، تگ `v1.0`.
- **نصب‌کننده ۱٫۰٫۲** — تمام شد ۲۷ اکتبر ۲۰۲۶: روی هر دو سرور لایو تست شد (نود + هاب، BBR، حفظ گواهی آی‌پی، بدون دست خوردن نگهبان و تانل).
